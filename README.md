# 日本の公開データ研究マップ

日本の公的統計を使った研究論文を集め、テーマ・データ源・解析データの年・研究の型で探せるようにした知見マップである。
収載は 1,248本（2026年9月24日時点）。分類は TypeSafe の判定モデル Jev による機械判定で、人手による確認は行っていない。

## 収載範囲

主解析のデータが次のどちらかに当たる論文を収載した。

| B 政府統計の個票 | 二次利用申請で得た政府統計調査の個票（国民生活基礎調査、国民健康・栄養調査、患者調査、人口動態調査の死亡票など） | 443 |

## 方法

1. **収集。** 27種類のデータ源について、Europe PMC で「データ源の英語名 AND (Japan OR Japanese)」を本文まで含めて検索した（MEDLINE と PMC 収載分）。データ源の名称は方法欄にだけ書かれることが多く、題名・抄録だけの検索では取りこぼすためである。重複を除いて 8,386本。
2. **一次判定。** 題名と抄録を Jev に渡し、区分（A／B／A＋B／範囲外／実証研究でない／判定不能）を判定した。A・B・A＋B・判定不能の 1,934本を候補とした。
3. **本文の取得。** 候補のうちオープンアクセスの論文は Europe PMC から全文を取得し、方法欄と結果欄を抜き出した。883本は本文で、365本は題名と抄録で判定した（収載論文の内訳）。
4. **詳細判定。** 候補の全件について、次節の項目を Jev で判定した。1本あたり約75問を1回の問い合わせで聞いている。
5. **テーマの追加。** テーマ未分類の論文と、主曝露・主アウトカムが既存テーマに当たらない論文から新テーマの候補を立て、Jev に「その概念の論文中の役割」と「既存テーマで足りるか」を判定させた。多数が新テーマを要するとした5つ（気象・環境曝露、環境負荷・脱炭素、障害・生活機能、生活時間・余暇、経済・産業）を加え、全件を判定し直した。それでも未分類だった5本のうち4本は、Claude（生成AI）が抄録から新カテゴリを提案し直し、同じ2段階の判定にかけた。Jev が支持した2つ（統計調査・データ基盤、自然現象・地球科学）を加え、収載論文すべてについて当てはまるかを判定した（収載論文での該当は32本と34本）。
6. **線の確認。** 問いの型が「関連の検討」または「制度・出来事の評価」の論文について、主曝露→主アウトカムの組合せを実際に解析したかを Jev に判定させた。「実際に解析した」ものだけを線として残し、47件（調整のみ、背景のみ、判定不能）を外した。
7. **論文のつながり。** OpenAlex から参考文献リストと被引用数を取得し、参考文献の重なり（書誌結合）、直接引用、共引用、テーマの重なりから、論文どうしの近さを計算した。参考文献を取得できた論文は 1,145本、テーマの重なりだけで結んだ論文は 103本。
8. **日本のデータかの確認。** 区分の定義が日本の統計を例示するだけで、日本のデータであることを条件として明記していなかったため、収載候補すべてについて「主解析のデータが日本のものか」を Jev で判定し、該当しない 70本（韓国、台湾、英国、カナダなど）を外した。
9. **著者名の補完。** Europe PMC の著者情報で名がイニシャルだけの論文は、OpenAlex のフルネームで補い、イニシャル表記も検索できるようにした。

## 判定項目

| 項目 | 内容 |
|---|---|
| 区分 | A／B／A＋B（収載外の区分を含めて判定） |
| データ源 | 検索に当たった各データ源を、解析に使ったか（確率 0.5 以上を使用とみなす） |
| 解析データの年 | 解析に用いたデータの最初の年と最後の年 |
| 問いの型 | 関連の検討、複数要因の探索、実態の記述、推移、地域差、制度・出来事の評価、尺度の検証、方法の検討、その他 |
| デザイン | 横断、反復横断、縦断、生態学的研究、時系列、尺度の検証、方法論、その他 |
| 対象集団 | 国民全体、成人、高齢者、子ども、新生児・出生、女性、妊産婦、就労者、患者、医療従事者・医療機関、世帯、その他 |
| 分析単位 | 個人、世帯、都道府県、市区町村・二次医療圏、全国集計、医療機関、その他 |
| 主曝露・主アウトカム | 65テーマのどれに当たるか（役割なし、該当テーマなし、判定不能を含む） |
| テーマ | 65テーマそれぞれについて、曝露・アウトカム・記述の対象・媒介・効果修飾・層別のいずれかとして扱ったか（調整変数のみは含めない） |
| 効果推定値の報告 | 信頼区間付きの推定値が報告されているか |

65テーマは15のグループにまとめて表示している（依存・嗜好、デジタル・情報、精神・心理、人間関係・社会的経験、感染症・予防、医療利用・疾病管理、生活習慣・身体健康、妊娠・家族・性、就労・社会経済・地域、疾病・死亡、医療提供・医療資源、人口・発育、環境・経済、データ・方法）。定義は `data/schema_od_v3.json` にある。

## 作り直す手順

```sh
python3 scripts/fetch_epmc.py          # 収集（data/epmc_cache/ に検索結果を保存）
zsh -lc 'python3 scripts/judge_jev.py' # 一次判定
python3 scripts/fetch_fulltext.py      # 本文の取得
python3 scripts/fetch_openalex.py      # 参考文献と被引用数
python3 scripts/fetch_openalex_authors.py  # 著者のフルネーム
zsh -lc 'python3 scripts/structure_v2.py --workers 12'  # 詳細判定
zsh -lc 'python3 scripts/followup_jev.py'               # 線の確認と該当テーマなしの再判定
zsh -lc 'python3 scripts/japan_check.py'                # 日本のデータかの判定
python3 scripts/build_viewer.py        # 画面の生成（viewer/index.html）
cp viewer/index.html index.html
```

Jev は、TypeSafe の API キーと、`jev.call(state, questions)` を持つ小さなクライアント（`~/.codex/skills/jev/scripts/jev.py` に置く想定）で呼び出す。API キーは環境変数 `TYPESAFE_API_KEY` か `~/.config/typesafe/env` から読む。OpenAlex への問い合わせには環境変数 `OPENALEX_MAILTO` に連絡先メールを入れる。本文（`data/fulltext/`）と Jev の生応答は容量と著作権のためリポジトリに含めていない。判定は処理済みの論文を飛ばすので、途中で止まっても再実行すれば続きから進む。`followup_jev.py` と `japan_check.py` も判定済みの分を飛ばす。

## 限界

- 分類はすべて機械判定で、人手の確認を経ていない。例外は、1本（One Health の評価枠組みの論文）のテーマと、該当テーマなしの再判定の採否で、いずれも Claude（生成AI）が題名・抄録と照合して決めた。この1本に割り当てた2テーマのうち、Jev が支持したのは居住・都市環境だけである。
- 336本は題名と抄録だけで判定した。本文の方法欄にしか書かれていない情報（データ源、解析データの年）は取りこぼしがありうる。
- 収集は英語名での検索による。和文誌のうち Europe PMC に収載されていないものは含まれない。
- 主曝露・主アウトカムが既存テーマに当たらない箇所が23残っている。
- 線は各論文の主曝露→主アウトカムの1組だけである。複数要因の探索や副次解析の組合せは線にしていない。
- 空欄やテーマの小ささは、その組合せの研究が存在しないことを意味しない。線は解析の組合せを示すもので、因果関係は示さない。
